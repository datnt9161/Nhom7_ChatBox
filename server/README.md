# 🖥️ CHAT BOX SERVER

## 📁 Files
- `server.py` - Main server
- `client_handler.py` - Client processing  
- `file_handler.py` - File transfer
- `server_manager.py` - Server management

## 🚀 Chạy server
```bash
cd server
python server_manager.py
```

## 🔧 APIs hỗ trợ
- Authentication: LOGIN, REGISTER
- Messaging: PUBLIC, PRIVATE
- File Transfer: FILE_SEND, FILE_REQUEST
- User Management: USERLIST, JOIN, LEAVE
- System: PING/PONG, ERROR, STATS, NOTIFICATION
